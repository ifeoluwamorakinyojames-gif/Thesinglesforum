Set up your TSF admin password

Choose and save your password in your password manager first. This tool generates settings on your phone. It does not send your password or generated values to a server, and it does not change your current login.

Add these in Cloudflare

Open TSF Worker → Settings → Runtime variables and secrets. Add each name below with type Secret, then save and deploy the changes. Keep AUTH_MODE set to standalone.

Keep this tab open while you add both values. Don't send screenshots of these values. Generating values again does not change the website until you replace its Cloudflare Secrets.

After saving both Secrets, visit /admin and sign in with the password you chose.
